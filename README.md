📌 О проекте
CRYPTONIX — это десктопное приложение для анализа локальных сетей. Оно позволяет:

Сканировать IP-адреса в заданном диапазоне

Определять открытые порты (основные, пользовательские, приватные, все)

Получать MAC-адреса через ARP-запросы

Определять операционную систему по TTL и открытым портам

Работать с баннерами сервисов (HTTP, SSH, FTP, SMTP, SMB, RDP)

Выгружать результаты в текстовый файл

Переключать темы оформления (8 тем, включая тёмную и фиолетовую)

Использовать интерфейс на русском или английском языке

⚡ Основные функции
Функция	Описание
📡 Сканирование IP	Поддерживает одиночные IP, CIDR-маски (/24, /16) и диапазоны (192.168.1.1-192.168.1.254)
🔌 Сканирование портов	Основные (1-1023), пользовательские (1024-49151), приватные (49152-65535), все порты или пользовательский список
🖥️ Определение ОС	Windows, Linux, macOS, FreeBSD, Cisco IOS — по TTL и открытым портам
📦 MAC-адрес	Получение через ARP-запрос (WinAPI)
🌐 Hostname	Обратное DNS-разрешение
📤 Выгрузка	Экспорт результатов в TXT с заголовками
🎨 Темы	8 тем: Светлая, Тёмная, Жёлтая, Морская, Пастельная, Мятная, Лавандовая, Фиолетовая
🌍 Локализация	Русский / English
🔄 Асинхронность	Многопоточное сканирование (async/await) без зависания интерфейса

🧪 Установка и запуск
Требования
Windows 7/10/11

.NET 6.0 Runtime или выше

Visual Studio 2022 (для разработки)

Запуск
Скачай релиз с GitHub Releases

Распакуй архив

Запусти CRYPTONIX.exe

Или скомпилируй из исходников:

bash
git clone https://github.com/kurayamivexyami/CRYPTONIX.git
cd CRYPTONIX
dotnet build
dotnet run
⚙️ Пример использования
Введи IP-диапазон: 192.168.1.1/24 или 192.168.1.1-192.168.1.254

Выбери режим портов: Основные (1-1023)

Нажми Сканировать

Получи список устройств с их IP, MAC, именем, ОС и открытыми портами

Выгрузи результат в TXT или открой IP в браузере по клику
